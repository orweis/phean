Instinct publishes no API or connector settings yet, so it cannot connect to Phean's MCP server directly. This page will carry the steps once it can.

## Until it connects

- **Capture what it does.** Instinct acts through your email, calendar and accounts. An agent that does connect (Claude Code, or [your own bot](/docs/your-own-bot)) can sweep those sources and capture its follow-ups as tasks, with links to the source.
- **Ask from one place.** Decisions about that work then reach you on the Decisions page with the rest, instead of in Instinct's app alone.

## When it does

The pattern will be the one every agent follows: add the workspace's URL, `https://<your-domain>/mcp/w/<slug>`, approve the agent in your browser, give it the [instructions to give any agent](/docs/agents#instructions-to-give-any-agent), and have it [sync up](/docs/agents#sync-up) on each run.
